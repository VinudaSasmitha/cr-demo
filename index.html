🎯 Goal: understand page structure

🏠 First, what is HTML?

HTML means HyperText Markup Language. It gives a web page its structure. Think of a website like a house:

🧱

HTML = Structure

The walls, doors and rooms. HTML says what content exists and what it means.

🎨

CSS = Appearance

The paint, colours, layout and decorations. CSS makes the page look beautiful.

⚡

JavaScript = Behaviour

The switches and moving parts. JavaScript makes the page interactive.

🧠 Tiny memory trick: HTML builds the structure. CSS dresses it up. JavaScript makes it do things.

🧩 The six important terms

Read each card, then explain it in your own words. That is how you know you understand it!

<!DOCTYPE html>

Tells the browser to use modern HTML standards mode. It is a declaration, not a normal HTML element, so it does not need a closing tag.

Write it first

<html lang="en">

The root element: the main container for the whole HTML document. lang="en" says the page language is English.

Whole document

<head>

Holds information about the page, such as its title, character encoding, metadata and links to CSS files. It is not the main visible content area.

Page information

<title>

Sets the document title, usually shown in the browser tab. Put it inside <head>, not inside <body>.

Browser tab name

<body>

Contains the main page content, such as headings, paragraphs, images, links and buttons.

Page content

<!-- comment -->

A note for people reading the source code. The browser does not show it as normal page content. Never put passwords or secrets in comments.

Developer note

🪆 Tags are like boxes inside boxes

An opening tag starts an element. A closing tag usually has a slash / and ends that element.

<body> <!-- opening tag --> <h1>Hello!</h1> <!-- heading element --> </body> <!-- closing tag -->
Remember: Some elements, such as <meta> and <img>, are void elements and do not need closing tags. But <html>, <head>, <body>, <title>, <h1> and <p> normally do.

🧠 The complete page skeleton

Learn the shape first. You do not have to memorise every extra line today.

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My First Website</title> </head> <body> <!-- Visible page content starts here --> <h1>Hello, world!</h1> <p>I am learning HTML.</p> </body> </html>

What is the viewport line? It helps the page use the device's width on phones and other screens. UTF-8 is a character encoding that supports many languages, including Sinhala.
